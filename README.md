# しらべノート

文献の出典・教員や友人のフィードバック・自分の調査データ・アンケートを1か所で管理し、引用表記(APA風 / 日本語論文風)をワンクリックで生成するシングルページのWebアプリです。

## 機能
- 資料の種類(書籍・論文・PDF・Web・その他)ごとに登録し、種類に応じた書式で引用を生成
- 出典の登録・編集・削除(タイトル、著者、発行年、出版社/掲載誌、URL、タグ、メモ、読書状態)
- 検索・種類/状態フィルタ・並べ替え・タグ絞り込み
- 引用の個別コピー / 全件まとめてコピー
- JSONでの書き出し・読み込み(端末間の移行用)

## タブ
- 🏠 ホーム: 提出期限のカウントダウン、未対応フィードバック、根拠不足の主張、未完了チェック、進行中アンケートを一覧
- 📚 出典: 書籍・論文・PDF・Webなど種類別の登録と引用生成。出典ごとに「引用箇所」(本文ページ・PDFの何枚目・引用文/要約・メモ)を保存し、本文用の引用表記をコピー
- 🔖 引用一覧: すべての出典の引用箇所を横断表示。用途ラベル(定義・主張・データ・手法・反論・背景)で色分け、画像(スクリーンショット)・自分のコメント・使う主張を付けられ、一覧をMarkdownでコピー可能
- 💬 フィードバック: 教員・友人などからの助言、対応状況、関連する章・主張との紐付け
- 🧩 主張・根拠: 章・節ごとに主張を整理し、根拠(出典・調査データ・アンケート)を紐付け。根拠不足フラグ・ピン留め・章の1行要約
- 📐 章立て: 章ごとの目標字数・現在字数・進捗、貼り付けた本文の字数カウント、主張/未対応フィードバックの件数
- 📊 調査データ: 取得方法・保存先リンク・CSV貼り付け
- 📝 アンケート: フォーム/結果のURL、締切、回答数の進捗
- 📑 参考文献: 本文を貼ると「(著者, 年)」「著者(年)」の引用を拾って出典と突き合わせ(未使用の出典・登録漏れの候補を表示)、参考文献リストを一括生成(本文で使われているものだけ等・和文→欧文順)
- ✅ 提出前: チェックリスト(雛形あり・要確認メモ)、提出ログ、未完了だけを集める直前ビュー

## 表示テーマ
右上の「🌓」ボタンで、自動(端末の設定に合わせる)・ライト・ダークを切り替えられます。

## バックアップ(重要)
データはブラウザ内(localStorage)にだけ保存されます。ホームの「今すぐバックアップ」→「ファイルに保存」でJSONを書き出し、定期的に保管してください。別の端末へは「読み込み」→「ファイルを選ぶ」で移せます。

## DOI・ISBNから自動入力
出典の追加画面でDOIまたはISBNを入れると、タイトル・著者・発行年などが入ります(DOI: Crossref、ISBN: openBD / Google Books)。インターネット接続が必要です。必ず内容を確認してから保存してください。

## スマホ・PCにアプリとして入れる(PWA)
GitHub Pages などhttpsで公開すると、ブラウザの「ホーム画面に追加」「インストール」からアプリとして使え、オフラインでも開けます。`index.html` を更新したら `sw.js` の `CACHE` のバージョンを上げてください。

## 使い方
`index.html` をブラウザで開くだけで動きます。ビルド不要・外部通信なし。
データはブラウザの localStorage に保存されます。

## 追加機能(v8)

- **🔍 全タブ横断検索**: `Ctrl`+`K` または `/` で、出典・引用箇所・フィードバック・主張・章・データ・アンケート・チェックをまとめて検索
- **＋ 引用のすばやい追加**: 右下の「＋ 引用」ボタン、またはキー `q`。出典を選んで連続入力でき、「保存して次を追加」に対応
- **削除の「元に戻す」**: 削除すると画面下に「元に戻す」ボタンが数秒出ます
- **ファイルへの自動保存・同期**(PCのChrome・Edge、https で開いたとき): ホームで保存先のJSONを選ぶと、変更のたびに自動保存。OneDrive・Google Driveなどの同期フォルダに置くと複数PCで同じデータを使えます。ファイルの方が新しい場合は、読み込み・統合・上書きを選べます
- **サンプルデータ・使い方ガイド**: データが空のときのウェルカム表示、サンプルだけを削除できる機能、ヘッダーの「❓ 使い方」、キー `?`

> 共有したページを開いた友人のデータは、その人のブラウザの中だけに保存されます(お互いのデータは見えません)。

## 追加機能(v9)

- **BibTeX / RIS 取り込み**: 出典タブの「BibTeX/RISを取り込む」から、Google Scholar・CiNii・Zotero・Mendeleyなどの書き出しを一括登録(タイトル+発行年が同じものは重複として除外)
- **出典の逆参照**: 出典カードに「この出典を根拠にしている主張」を表示
- **1日あたり必要字数**: 提出期限を入れると、章立てに「残り字数÷残り日数」を表示
- **🗓 面談ログ**: 日付・相手・話した内容・宿題・次回日を記録
- **💡 保留・没ネタ**: 使わなかったアイデアを理由つきで保管(保留/没/採用)
- **📅 カレンダー書き出し(.ics)**: 提出期限・回収中アンケートの締切・面談の次回日を、Googleカレンダー/Outlook用に出力
- 修正: 再読み込みで最終更新時刻が失われ、ファイル同期の確認が不要に出る場合がある問題

## 追加機能(v10)

- **📋 今日やること**: ホーム上部に、近い締切(提出期限・アンケート・面談)、1日あたり必要字数、未対応のフィードバックなどを1か所に集約
- **引用の使用状況**: 各引用箇所に「✓ 本文で使った」を記録し、引用一覧で未使用/使用済みに絞り込み
- **タグの横断検索**: タグをクリックするか、検索で `#タグ名` を入力すると、出典・フィードバックをタブをまたいで表示。検索欄を空にするとタグ一覧が出ます
- **章ごとの根拠カバー率**: 章カードと全体に、根拠(出典・データ・アンケート・引用箇所)が紐づいた主張の割合と、未紐づけの主張を表示
- **引用チェックの強化**: 本文の末尾に「参考文献」見出しとリストも貼ると、本文との過不足・登録外の行を突き合わせ。直接引用らしいのにページ番号がない箇所も指摘
- **📄 PDFテキストから引用を選ぶ**: PDFからコピーした文章を貼ると、改行やハイフンを整えて文に分け、選んだ文をページつきで引用に追加(PDF本体は読み込まず、データは端末内に留まります)

## 手入力をラクにする機能(v12)

- **CiNii・J-STAGEの3行形式にも対応**: 検索結果の「タイトル / 著者 / 雑誌名 (号) ページ 年月」をそのまま貼り付けると、各欄に振り分けます(「査読有り」などの表示は無視)
- **参考文献の1行から入力**: 出典フォームに既存の参考文献を1行貼り付けて「分解」すると、著者・年・タイトル・出版社/雑誌・巻号ページ・URLを振り分けます(内容は目視で確認してください)
- **入力の自動整形**: 全角の数字・記号、「pp.45–47」、「A and B」「A; B」などを自動で正しい形に直します
- **候補表示**: 著者・出版社は登録済みの候補が出て、タグは既存タグをクリックで追加できます
- **引用の連続入力**: 用途ラベルはボタンで選択、前回の用途・種類を引き継ぎ、「保存して次を追加」ではページと使う主張も引き継ぎます。ページ欄には前回のページを表示
- **PDFからの貼り付け**: 引用文に貼ると途中の改行を自動で除去(「改行を整える」ボタンもあります)
- **Ctrl+Enter(⌘+Enter)** で出典・引用を保存

## 書き出し・整理(v14)

ヘッダーの「🗂 データ」にまとめました(バックアップもここに移動)。

- **Word / Markdown書き出し**: 参考文献リスト・引用箇所・主張と根拠・章立てと字数から含める内容を選んで、.docx または Markdown で出力。Wordは見出し・参考文献のぶら下げインデントつきで、そのまま提出物の下書きにできます(外部ライブラリなしで生成)
- **スナップショット**: 提出・発表時点の状態を保存し、「いまとの差分」の確認や「この状態に戻す」ができます(画像は容量節約のため含めず、戻すときは現在の画像を引き継ぎます)
- **重複出典の検出と統合**: DOI・URL・タイトル・著者/年から重複候補を検出。統合すると引用箇所・タグ・メモをまとめ、主張の根拠の紐づけも付け替えます。新規登録時とホームの「今日やること」でも知らせます
- **一括操作**: 出典・引用一覧タブの「☑ 選択」で複数選択し、状態変更・タグ追加・削除(出典)、用途変更・使用済み切替・削除(引用箇所)をまとめて実行
- 削除・統合・復元は、画面下の「元に戻す」で取り消せます
